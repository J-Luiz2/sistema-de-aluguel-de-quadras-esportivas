🏟️ Sistema de Aluguel de Quadras Esportivas

1. Apresentação do Projeto

O projeto consiste no desenvolvimento de um sistema de aluguel de quadras esportivas e campos de society, com o objetivo de facilitar a busca, a consulta e a reserva desses espaços.

Atualmente, encontrar quadras disponíveis para aluguel pode ser um processo trabalhoso, pois muitas vezes as informações sobre localização, preços, modalidades esportivas e horários disponíveis estão dispersas em diferentes plataformas ou dependem do contato direto com os estabelecimentos.

Diante desse cenário, o sistema busca centralizar essas informações em uma única plataforma, permitindo que os usuários encontrem espaços esportivos, consultem suas características e tenham mais facilidade para realizar reservas.

Problema real que o sistema resolve

A dificuldade de encontrar e alugar quadras esportivas de maneira prática e organizada, principalmente pela falta de centralização das informações e de um meio acessível para consultar preços, características dos espaços e disponibilidade de horários.

Objetivo

Oferecer uma plataforma que conecte pessoas interessadas em praticar esportes aos estabelecimentos que disponibilizam quadras e campos de society para aluguel, tornando o processo de busca e reserva mais simples, rápido e acessível.

3. Como usamos Inteligência Artificial

Durante o desenvolvimento dos protótipos, utilizamos inteligência artificial como ferramenta de apoio para a criação das interfaces visuais do sistema.

Ferramenta utilizada

Google Stitch

O Google Stitch foi utilizado para gerar propostas de interfaces a partir de descrições textuais, auxiliando na definição da aparência, organização e disposição dos elementos das telas.

Prompt utilizado

O que foi aproveitado?

- A estrutura visual das telas geradas.
- A organização dos elementos e das informações.
- As sugestões de cores e componentes visuais.
- A disposição das informações sobre os espaços esportivos.
- As referências de navegação e experiência do usuário.

O que foi modificado?

Após analisar as interfaces geradas, o grupo avaliou quais elementos atendiam melhor às necessidades do projeto. Algumas disposições de componentes, informações e elementos visuais foram ajustadas para tornar a plataforma mais adequada à proposta de aluguel de quadras esportivas.

As decisões sobre as funcionalidades, a organização do sistema e os requisitos do projeto foram definidas e avaliadas pelos integrantes do grupo.
